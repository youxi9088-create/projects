# 星图档案 · 设计令牌表（Design Tokens）

> 全部以 CSS 自定义属性形式定义在 `apps/web/src/index.css` 的 `:root` 中。
> 硬约束遵循情况：**中性色阶 5 阶 ✅ ／ 强调色 1 主 + 1 辅 + 1 点缀 ✅ ／ 阴影 3 档 ✅ ／ 圆角 3 阶 ✅ ／ 间距 4pt 网格 ✅ ／ 动效 3 档 ✅**
> 本文所有 hex 均为实测值，对比度数据见文末「校验结果」一节。

---

## 一、中性色阶（5 阶，硬性上限）

色相锁定在暖棕 `H≈28°–32°`，饱和度压到 `S≈30%–34%`（旧版深棕饱和度高达 45%+，是"发油"的主因）。相邻阶明度差 ≥ 4.3%，肉眼可辨。

| Token | 值 | HSL 明度 | 与上一阶对比 | 用途 |
|---|---|---|---|---|
| `--neutral-1` | `#171009` | 6.3% | — | **页面最底层**：`.app-shell` / `.game-shell` / `.creator-shell` 背景；遮罩基底 |
| `--neutral-2` | `#261b12` | 11.0% | 1.12 | **内嵌面**：输入框 `textarea`、代码块 `pre`、进度轨道、`.target-card` 静置底 |
| `--neutral-3` | `#352719` | 15.3% | 1.17 | **面板**：`.app-nav`、`.topbar`、`.mission-panel`、`.creator-nav`、`.case-breadcrumb` |
| `--neutral-4` | `#463522` | 20.4% | 1.23 | **卡片**：`.level-card`、`.theme-card`、`.gallery-grid article`、`.shelf-book`、`.map-node` |
| `--neutral-5` | `#584430` | 26.7% | 1.27 | **抬升态**：卡片 hover、`.choice.is-selected`、`.app-nav-links button.is-active`、chip 激活 |

### 语义别名（不新增色阶，仅指向上面 5 个值）

| Token | 指向 | 用途 |
|---|---|---|
| `--surface-base` | `var(--neutral-1)` | 页面根背景 |
| `--surface-sunken` | `var(--neutral-2)` | 内嵌控件底 |
| `--surface-panel` | `var(--neutral-3)` | 面板底 |
| `--surface-card` | `var(--neutral-4)` | 卡片底 |
| `--surface-raised` | `var(--neutral-5)` | 悬浮/激活底 |
| `--surface-scrim` | `rgba(23,16,9,.72)` | 弹窗/过场遮罩（由 neutral-1 派生） |

## 二、材质层：牛皮纸（Material，不占中性色阶位）

牛皮纸是**材料**而非明度阶梯，因此单列。用于所有承载正文阅读的"纸片"。

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#e9dcbe` | 牛皮纸/拍立得纸面：`.home-case-preview`、`.completion-card`、`.hint-toast`、`.case-intro-card`、`.notes-list article`、`.chapter-outline article` |
| `--paper-shade` | `#d9c9a4` | 纸张折痕/次级纸面/细网格线；**不承载正文文字**（其上文字对比度 4.26，仅达 AA-large） |

> 说明：纸张与 `--neutral-1` 的对比度为 **13.86:1**，能形成明确的"纸贴板上"层级，这是新版替代大投影的核心手段。

## 三、强调色（1 主 + 1 辅 + 1 点缀）

| 角色 | Token | 值 | HSL | 用途 |
|---|---|---|---|---|
| **主 · 黄铜琥珀** | `--accent-primary` | `#e5b76b` | H39 S62% L66% | 主行动按钮底、当前步骤、active 导航、链接 hover、eyebrow 文字、图钉高光、进度强调 |
| **辅 · 鼠尾草绿** | `--accent-secondary` | `#94b184` | H105 S24% L61% | 已找到（`.target-card.is-found`）、已完成步骤（`.is-done`）、信息面板（`.design-handoff-summary` / `.model-deliverables`）、成功态 |
| **点缀 · 铁锈朱砂** | `--accent-danger` | `#db825b` | H17 S61% L61% | 错误与警示：`.config-error`、`.generator-error`、`.production-error`、误点计数、"未读"装饰图钉 |

**为什么主色选 `#e5b76b` 而不是旧版 `#e1a74c`**：旧值饱和度 72%、偏橙红（H36），在深棕大面积底上会产生"油光"感并让暗部发脏。新值把饱和度降到 62%、色相右移到 39°、明度从 59% 提到 66%，保留金色调性但氧化感消失。

## 四、文字色

| Token | 值 | 主要承载面 | 对比度（对 `--surface-panel`） |
|---|---|---|---|
| `--text-primary` | `#f6ead2` | 标题、正文、强数字 | **12.10 ✅ AA** |
| `--text-secondary` | `#cdb693` | 段落、描述、次要信息 | **7.36 ✅ AA** |
| `--text-tertiary` | `#b09474` | eyebrow、占位符、禁用态、面包屑父级 | **5.04 ✅ AA** |
| `--text-on-paper` | `#3b2a17` | 牛皮纸上的墨色标题与正文 | **10.10 ✅ AA**（对 `--paper`） |
| `--text-on-paper-soft` | `#6b563a` | 牛皮纸上的次级墨色 | **5.12 ✅ AA**（对 `--paper`） |
| `--text-on-accent` | `#241703` | 琥珀按钮上的文字 | **9.44 ✅ AA**（对 `--accent-primary`） |
| `--text-success` | `#bcd4ac` | 成功态表面上的文字 | **7.55 ✅ AA**（对 `--surface-success`） |
| `--text-danger` | `#f0b9a4` | 错误态表面上的文字 | **8.05 ✅ AA**（对 `--surface-danger`） |

**统一的文字使用规则**：`--text-primary` / `--text-secondary` / `--text-tertiary` 只用于**深棕表面**；`--text-on-paper` / `--text-on-paper-soft` 只用于**牛皮纸表面**。两者不得混用（旧版大量米白色直接压在深底上，是对比度失控的源头）。

## 五、描边色（语义别名，不新增色相）

| Token | 值 | 用途 | 非文本对比（对 `--surface-panel`） |
|---|---|---|---|
| `--border-subtle` | `#352719`（= neutral-3） | 面板内分隔线、装饰性边 | 1.57（装饰性，不要求 3:1） |
| `--border-default` | `#584430`（= neutral-5） | 卡片/面板外框、hover 前的默认边 | 1.57（装饰性） |
| `--border-control` | `#947d5e` | **交互控件**（input / select / textarea / button）的边；必须满足 WCAG 1.4.11 | **3.68 ✅ ≥3:1** |
| `--border-accent` | `#e5b76b`（= accent-primary） | 选中态、聚焦态、主按钮边 | 7.77 |

> 只有 `--border-control` 承担"控件可辨识性"，因此它是唯一被强制要求 ≥3:1 的描边。

## 七、焦点环

| Token | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--focus-ring` | `#f2c985` | `:focus-visible` 的 `outline` 颜色 | 对 base **12.09** ／ 对 panel **9.25** ／ 对 card **7.51** ✅ |

规范（替换 `index.css` 现有第 21 行）：

```css
:where(button, a, input, textarea, select, [tabindex]):focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
  border-radius: var(--radius-sm);   /* 让环跟随控件圆角 */
}
```

> 旧版 `outline: 3px solid` + `outline-offset: 3px` 在 44px 高按钮上会溢出容器，改为 2px / 2px。

## 八、阴影（仅 3 档，硬性上限）

统一使用暖黑 `rgba(23,13,6,α)` 而非纯黑 `#000`，避免深色底上出现"死黑边"。

| Token | 值 | 用途 | 允许使用的组件 |
|---|---|---|---|
| `--shadow-1` | `0 1px 2px rgba(23,13,6,.32)` | 纸片浮在板上的最小提示 | 所有静态卡片、拍立得、牛皮纸标签 |
| `--shadow-2` | `0 4px 14px rgba(23,13,6,.36)` | hover / 选中抬升 | `.level-card:hover`、`.theme-card.is-selected`、`.config-error` |
| `--shadow-3` | `0 14px 36px rgba(23,13,6,.44)` | 脱离页面的浮层 | `.completion-card`、`.hint-toast`、`.production-error` |

**禁止**：任何组件使用三层以上 `box-shadow`；任何组件在 `box-shadow` 之外再叠 `radial-gradient` 或 `::after` 渐变遮罩（见 `项目案例-隐藏物品游戏-03-UI视觉方向.md` P1）。

## 十、间距（4pt 网格）

| Token | 值 | 典型用途 |
|---|---|---|
| `--space-1` | `4px` | 图标与文字间隙、chip 内边距 |
| `--space-2` | `8px` | 网格 gap（`.target-list`、`.upload-list`）、拍立得内白边 |
| `--space-3` | `12px` | 卡片内边距（紧凑）、按钮组 gap |
| `--space-4` | `16px` | **标准间隙**：面板内边距、同级区块间距 |
| `--space-5` | `20px` | 页面外边距（≤ 600px）、卡片 gap |
| `--space-6` | `24px` | 卡片内边距（标准）、Hero 内边距（移动端） |
| `--space-8` | `32px` | 章节间距、`.home-section` 上间距 |
| `--space-10` | `40px` | 大区块分隔 |
| `--space-12` | `48px` | Hero 内边距（桌面）、`.production-page` 顶部 |
| `--space-16` | `64px` | 页面级留白、Hero 内边距（宽屏） |

**非 4 的倍数值必须清除**：现有代码中的 `9px`（`.game-shell` gap、`.audio-controls` gap、`.creator-footer` gap）、`7px`（多处）、`13px`、`14px`（`.level-select` gap）、`18px`、`.story-page min-height` 等一律就近归到网格。

## 十一、动效（3 档，硬性上限）

| Token | 值 | 用途 |
|---|---|---|
| `--motion-fast` | `120ms` | 颜色/描边/透明度变化：hover、active、focus |
| `--motion-base` | `200ms` | 位移与缩放：卡片 hover 上浮、图片 `scale`、`.hint-toast` 进出 |
| `--motion-slow` | `320ms` | 大面积变换：`.production-track li` 状态切换、弹窗入场、过场淡入 |
| `--ease-out` | `cubic-bezier(.22,.68,.32,1)` | 全站统一缓动（唯一允许的 easing） |

**过渡属性白名单**：只允许 `color` / `background-color` / `border-color` / `opacity` / `transform` / `box-shadow`。**禁止**过渡 `filter`（现有 `.my-cases-button svg` 与多处 `:hover { filter: brightness(1.12) }` 必须改成 `background-color` 变化）——`filter: brightness` 会连带改变饱和度观感，是"发油"的元凶之一。

## 十四、校验结果（实测）

| 检查项 | 结果 |
|---|---|
| 中性阶相邻明度差 | 4.7% / 4.3% / 5.1% / 6.3%（全部 ≥ 4.3%，可辨） |
| `--text-primary` on panel | 12.10 ✅ AA |
| `--text-secondary` on panel | 7.36 ✅ AA |
| `--text-tertiary` on panel | 5.04 ✅ AA |
| `--accent-primary` on panel | 7.77 ✅ AA |
| `--accent-secondary` on panel | 6.10 ✅ AA |
| `--accent-danger` on panel | 5.05 ✅ AA |
| `--text-on-paper` on `--paper` | 10.10 ✅ AA |
| `--text-on-accent` on `--accent-primary` | 9.44 ✅ AA |
| `--border-control` on panel | 3.68 ✅ ≥3:1（WCAG 1.4.11） |
