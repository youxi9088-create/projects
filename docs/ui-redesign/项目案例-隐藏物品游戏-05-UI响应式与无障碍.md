## 一、现有断点评估

### 1.1 现状清单

| 断点 | 影响的组件 | 评价 |
|---|---|---|
| `≤ 850px` | `.app-shell` 内边距、`.level-select` 单列、`.home-commission-section` 单列、`.generator-form` 纵向、`.audio-controls` 隐藏、`.story-beat` 隐藏、`.mistakes` 隐藏、`.home-hero` 单列、`.home-case-preview` 隐藏 | ⚠️ 与 760 仅差 90px，两者职责高度重叠，维护成本高 |

| `≤ 600px` | `.target-list` 四列 | ✅ 合理 |
| `≤ 500px` | `.topbar` 顶部对齐、`.progress strong` 20px、`.target-list` 两列、`.mission-panel` 单列、`.hint-button` 满宽、`.home-hero` 取消最小高、`.creator-footer`/`.share-actions` 纵向反转、`.upload-panel` 纵向、`.story-copy` 内边距、`.story-map` 单列、`.commission-mission` 四列、`.design-handoff-summary` 单列 | ⚠️ 500 不是主流机型宽度，480 才是；500–768 区间存在"半响应式"空白 |
| **缺失** | **≥ 1024px 与 ≤ 480px 两端、以及全部「高度」断点** | ❌ 3:2 横向画布只受宽度约束，矮屏笔记本（1366×768）与手机横屏完全没被覆盖 |

### 1.2 结论：调整为「5 宽度断点 + 3 高度断点」

**宽度断点**（保留原有 4 档的语义，微调数值并新增 1 档）：

| 代号 | 媒体查询 | 对齐的机型 | 相对现状 |
|---|---|---|---|
| `bp-lg` | `@media (max-width: 1024px)` | 小尺寸笔记本（1280 逻辑宽缩放）、iPad 横屏 | **新增** |
| `bp-md` | `@media (max-width: 860px)` | iPad Air 竖屏（820–834） | 原 850 → 860 |
| `bp-sm` | `@media (max-width: 768px)` | iPad mini 竖屏（744–768） | 原 760 → 768（对齐标准） |
| `bp-xs` | `@media (max-width: 600px)` | 折叠屏展开、大屏手机横屏 | 不变 |
| `bp-xxs` | `@media (max-width: 480px)` | iPhone SE 375 / 主流 390–430 | 原 500 → 480 |

> **合并建议**：`bp-md`(860) 与 `bp-sm`(768) 之间的 92px 区间内容差异极小，可将 `.level-select` 单列、`.home-hero` 单列等原 850 的规则**上移到 1024** 或**下移到 768**，最终只保留 **1024 / 768 / 480 三个主力断点**，860 与 600 仅保留无法归类的个别规则。推荐三主力断点方案以降低维护成本。

**高度断点（新增，游戏页专用）**：

| 代号 | 媒体查询 | 处理 |
|---|---|---|
| `bh-sm` | `@media (max-height: 720px)` | `--game-chrome: 152px`；`.progress strong` 降到 20px；隐藏 `.audio-controls` 文字只留图标 |
| `bh-xs` | `@media (max-height: 600px)` | `--game-chrome: 136px`；`.mission-panel` 降到 `min-height: 56px`；`.target-card` 降到 48px；`.app-brand` 隐藏文字只留 `✦` |
| `bh-land` | `@media (max-height: 480px) and (orientation: landscape)` | 手机横屏：`.target-list` 改 `grid-auto-flow: column` + `overflow-x: auto`；提示浮层强制走**方案 B**（顶部浮动）；`.app-nav-links` 隐藏 |

### 2.2 focus-visible 规范

**替换 `index.css` 现有第 21 行**（旧值为 `outline: 3px solid #f3c56e; outline-offset: 3px`）：

```css
:where(button, a, input, textarea, select, [tabindex]):focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
  border-radius: var(--radius-sm);
}
```

要点：

| 项 | 要求 | 说明 |
|---|---|---|
| 只用 `:focus-visible` | ✅ 必须 | 不得使用 `:focus`（鼠标点击不应出现焦点环） |
| 线宽 / 偏移 | 2px / 2px | 旧的 3px/3px 在 44px 控件上会溢出容器并被 `overflow: hidden` 裁掉 |
| 不得 `outline: none` | ✅ 必须 | 全站禁止任何 `outline: none` / `outline: 0`；若需隐藏默认轮廓，必须同时提供等效替代 |
| 焦点顺序 | DOM 顺序 | 不改 DOM 结构，故焦点顺序天然正确；`.hint-toast` 移入网格末行后仍在 DOM 末尾，不打断顺序 |
| 弹窗焦点管理 | 需工程侧补充 | `.completion` / `.outro-cutscene` / `.case-intro` 为 `role="dialog" aria-modal="true"`，打开时应把焦点移入卡片、关闭时还给触发元素；建议 `inert` 或 `aria-hidden` 屏蔽背景 |
| 键盘可达的画布 | 需工程侧补充 | Phaser `<canvas>` 应带 `tabindex="0"` 与 `aria-label`（如「寻物场景：雨夜书桌」），否则键盘用户完全无法进入游戏 |
| 禁用态 | — | `.target-card:disabled` 不可聚焦，符合预期；但见 §2.5 的补充说明 |

### 2.3 prefers-reduced-motion

现状 `App.css` 第 282 行的全局规则：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }
}
```

**问题**：这把「找到物品」的 `target-found` 反馈动画也一并抹掉了。该动画是玩家唯一的即时正反馈，直接禁用会让"找到"的手感消失。

**修正方案**——保留规则骨架，但为反馈类动画提供**非运动替代**：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }

  /* 1) 找到物品：用颜色 + 描边变化替代缩放弹跳（无位移、无缩放） */
  .target-card.is-found { animation: none !important; }
  .target-card.is-found {
    border-width: 2px;
    box-shadow: inset 0 0 0 1px var(--accent-secondary);
  }

  /* 2) 卡片 hover：取消位移，只保留底色与描边变化 */
  .level-card:hover, .theme-card:hover, .creator-entry:hover,
  .shelf-book:hover, .target-card:hover {
    transform: none !important;
  }

  /* 3) 封面图缩放：完全禁用 */
  .level-card:hover .level-cover,
  .theme-card:hover img,
  .shelf-book:hover img { transform: none !important; }

  /* 4) 平滑滚动改为瞬时 */
  .home-cases-section { scroll-margin-top: var(--space-5); }
}
```
